Privacy Policy for CardFlip Memory

Last updated: September 25, 2026

CardFlip Memory is a memory card game developed by Diksha Rawat.

Information We Collect

CardFlip Match does not require users to create an account and does not collect names, email addresses, phone numbers, precise location, contacts, photos, or other personal information.

Local Game Data

Card Match stores game-related information such as scores, game statistics, and settings locally on the user's device. This information is used to provide the game's statistics and settings features.

Data Sharing

CardFlip Match does not currently transmit or sell this locally stored game information to third parties.

Advertising

The current version of Card Match does not contain advertising SDKs or display advertisements.

Data Security

Because the current version stores game data locally and does not operate an online account system, there is no Card Match server storing this game data.

Data Retention and Deletion

Local game data remains on the device until the user removes the app or clears its application data. Card Match does not maintain an online user account or remote personal-data database.

Children's Privacy

Card Match does not knowingly collect personal information from children.

Changes to This Privacy Policy

This privacy policy may be updated when the app's functionality or data practices change.
